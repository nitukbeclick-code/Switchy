## שלב 6ב — תבנית מאושרת אחת (אתה, לבד) — פותחת את הפולואפ

**למה זה חשוב:** WhatsApp מרשה טקסט חופשי רק בתוך חלון 24 שעות שה**לקוח** פותח
בכך שהוא כותב לנו. מחוצה לו Meta דוחה עם שגיאה `131047`, ורק **תבנית מאושרת**
עוברת. בלי תבנית — `savings-watch` (התראות ירידת מחיר) לא יכול להגיע לאף אחד
ששתק יממה, וזה בהגדרה כמעט כולם: התראה כזו נשלחת ימים אחרי ההודעה האחרונה.

הקוד כבר תומך בזה מקצה לקצה (`sendTemplate` / `sendProactive`), והוא **כבוי**
עד שתגדיר את הסוד. מה שנשאר הוא אישור מול Meta, שרק אתה יכול לעשות:

- [ ] `business.facebook.com` → **WhatsApp Manager → Message templates → Create**.
- [ ] קטגוריה: **Utility** (לא Marketing — אישור מהיר יותר ותמחור נמוך יותר,
      וזו באמת התראת שירות על מסלול שהמשתמש **ביקש** לעקוב אחריו).
- [ ] שפה: **עברית**. שם מוצע: `savings_alert`.
- [ ] גוף עם **פרמטר אחד בדיוק** — הקוד ממלא אותו במשפט העובדתי שמצטט את
      המספרים האמיתיים. לדוגמה:

      שלום, מצאנו עבורכם חיסכון: {{1}} להשוואה המלאה: switchy-ai.com

      ⚠️ הקישור בטקסט ה**קבוע** של התבנית, לא בפרמטר. פרמטרים הם מיקומיים —
      תבנית שאושרה עם מספר פרמטרים אחר תידחה בכל שליחה (יופיע בלוג
      `wa.sendTemplate` עם שם התבנית).
- [ ] אחרי אישור → Supabase → **Edge Functions → Secrets**:
      - [ ] `WHATSAPP_TEMPLATE_SAVINGS` = שם התבנית (למשל `savings_alert`).
      - [ ] `WHATSAPP_TEMPLATE_LANG` = קוד השפה **כפי ש-Meta רשמה אותה**
            (בדרך כלל `he`; אם נרשם `he_IL` — זה מה שצריך להיות כאן).

**איך תדע שזה עבד:** בתשובת ה-POST של `savings-watch` יש שלושה מונים —
`sentWhatsapp` (נמסר), `sentTemplate` (מתוכם, כמה ניצלו ע"י תבנית), ו-
`outsideWindow` (חלון סגור ולא הצלחנו להגיע). **לפני** התבנית `outsideWindow`
הוא כמעט כל שליחה; **אחרי** — הוא אמור לצנוח ו-`sentTemplate` לתפוס את מקומו.
אם `outsideWindow` נשאר גבוה גם אחרי ההגדרה, זו תבנית ש-Meta דחתה — חפש
`wa.sendTemplate` ב-Edge logs.
